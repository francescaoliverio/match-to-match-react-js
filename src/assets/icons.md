# Icone

Per usare un'icona:

1. **importare** con la riga corrispondente.
2. usare **come un componente** ([🔗 esempio](..\components\ExampleIcon.jsx))
3. si possono passare **props**, come: color, fontSize...

**Reference:**

- [Material UI](https://mui.com/material-ui/material-icons/?query=explo&theme=Outlined)
- [Instructions](https://mui.com/material-ui/api/icon/?_gl=1*1cfjh67*_up*MQ..*_ga*MTIxNDU5MTQuMTc3ODE0OTM2MA..*_ga_5NXDQLC2ZK*czE3NzgxNDkzNTkkbzEkZzAkdDE3NzgxNDkzNTkkajYwJGwwJGgw)

## Bottom NavBar
```js
// 🧭 explore
// -- outlined
import ExploreOutlinedIcon from "@mui/icons-material/ExploreOutlined";
// -- filled
import ExploreIcon from "@mui/icons-material/Explore";

// 🤝 match
// -- outlined
import HandshakeOutlinedIcon from "@mui/icons-material/HandshakeOutlined";
// -- filled
import HandshakeIcon from "@mui/icons-material/Handshake";

// 💬 chat
// -- outlined
import ChatBubbleOutlineOutlinedIcon from "@mui/icons-material/ChatBubbleOutlineOutlined";
// -- filled
import ChatBubbleOutlinedIcon from "@mui/icons-material/ChatBubbleOutlined";

// 👤 profile
// -- outlined
import PersonOutlinedIcon from "@mui/icons-material/PersonOutlined";
// -- filled
import PersonIcon from "@mui/icons-material/Person";

// add

```
